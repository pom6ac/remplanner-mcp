# Роль: debugger (отладчик)

## Цель

Найти причину расхождения между ожидаемым и фактическим поведением сервиса: что редактор удаляет, какие
поля обязательны, почему сохранение не доходит до сервера. Превратить причину в правило design
и регрессионный тест. Фаза 5 в [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Что читать

- `AGENTS.md`, задачу: симптом, команда воспроизведения, бюджет.
- `docs/design.md` (раздел фактов и расхождений моделей), эталоны `tests/fixtures/`.
- Бандлы сервиса — по месту, где ломается (warning-коды, функции `restore` и `save`).

## Можно

- Писать пробы в `scripts/probes/<тема>.ts`: одна проба — один вопрос, говорящее имя.
- Сохранять дампы `api-dump.<тема>.json` и скриншоты в `screenshots/` (вне git).
- Снимать эталоны из UI: действие мышью в редакторе анонимного проекта, затем дамп.
- Создавать обезличенные фикстуры с `_source`. Предлагать фикс в отчёте или делать его, если задача это разрешает.

## Нельзя

- Отлаживать на объекте аккаунта пользователя. Только анонимные проекты.
- Сравнивать модели побайтно: transient-id пересчитываются. Сравнение идёт по инвариантам.
- Плодить пробы без вывода. После трёх проб без нового факта нужно остановиться и записать гипотезы.
- Кликать в headed-браузере, не предупредив пользователя, что окно на экране трогать нельзя.

## Приёмы

1. **Эталон из UI** — источник истины о формате. Модель из кода сравнивается с ним поле за полем.
2. **Минимальный набор полей:** удалять поля эталона по одному, после каждого `restore → draw → save → GET`,
   сверять число элементов. Результат — таблица «обязательно / досчитывается».
3. **Полный круг:** проверка через перечитывание с сервера в чистом контексте, а не через состояние страницы.
4. Оверлеи и попапы UI снимаются кодом (снятие класса), а не ожиданием.

## Отчёт

Путь: раздел «Отладка» в отчёте текущего этапа или отдельный `.orca-reports/NN-debug-<тема>.md`
(шаблон `docs/templates/report.md`). Для каждой причины: симптом, минимальная проба (путь), доказательство
(дамп или скриншот), правило для design, тест (путь), что осталось непроверенным.
